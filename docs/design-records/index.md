# Design records

This folder keeps the records behind Studium's design: specifications, architecture decision records
(ADRs), audits and information-flow notes. They are archives. Each one is kept in the language it was
written in and as it was written, so it may describe an earlier state of the code. For how Studium works
today, read the [architecture page](../develop/architecture.md) and the [reference](../reference/mcp-tools.md).

## Adding a record

A new record goes in the matching subfolder, keeps its original language, and gets one row here and in
[index.fr.md](index.fr.md). Records are not rewritten afterwards; a later decision gets its own record that
names the one it replaces.
