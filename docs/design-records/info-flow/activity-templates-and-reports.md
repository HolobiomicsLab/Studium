# Information flow — activity templates and learner reports

The harness reads the current public operator context and the template catalogue.
It chooses a ready pattern, prepares an editable activity in a new workspace and
checks its input contract. Teacher/harness supplied data and source references
remain explicit; the preparer is not a scientific claim generator or executor.
The generated task tells the harness what can vary and what must be verified.

The browser receives public scene identifiers and activity inputs, not the raw
lesson answer keys, private host journal or harness credentials. An opted-in
semantic trace records explicit interactions, not every keystroke or the complete
conversation. Learner contributions are never generated by the teaching harness.
An automated audit uses a separate, labelled synthetic activity.

The learner chooses whether to export actions. The harness can pass that selected
file and/or a selected journal snapshot to the report tool. The tool validates the
source schemas, filters original text according to the export choice, then emits
structured report artifacts, ASTRA provenance, ARA links and MySTRA views. It does
not ask a model to infer what happened. Input validation and package checks run
before claiming technical integrity; absence of help events is reported as unknown.

| Information | Where it goes | Limit |
| --- | --- | --- |
| Public scene and selected template | Prepared task and local viewer | Does not establish teacher approval |
| Synthetic or supplied scientific inputs | Activity workspace | Status and checks remain explicit |
| Learner's recorded semantic actions | Explicit download | Partial browser history, client clock |
| Harness-declared assistance | Selected trace input | Declared, not authenticated execution |
| Private journal | Only if explicitly selected | Separate host sequence |
| Original free text | Report only on explicit inclusion | Storage consent is not sharing consent |
| ASTRA/ARA + exported evidence | MySTRA report | Provenance, not a learning score |
