## Une séance dans un harnais

L'agent lit la scène publique et son contrat, présente la tâche, attend la réponse
de l'étudiant, puis la soumet à Studium. Il peut utiliser ses propres outils pour
chercher une source, installer une bibliothèque dans l'environnement autorisé,
exécuter une capsule ou préparer un viewer. Le moteur conserve progression,
adaptation et formats ; l'étudiant conserve prédiction et jugement.

L'API ajoute authentification locale, identifiants de requête pour les relances,
refus des soumissions destinées à une ancienne scène et effacement des réponses
mises en cache lors de l'oubli. Elle utilise le registre partagé de MCP. La reprise
entre harnais nécessite **le même serveur encore actif** : un redémarrage ne
restaure pas la position. Le service REST historique reste distinct.

Un viewer HTML ne contient pas d'agent. Une demande de média peut être préparée à
l'avance, puis exécutée par le harnais si son outil est disponible. L'attachement
produit une nouvelle activité ; il ne migre pas silencieusement une activité déjà
ouverte. Aucune API payante de génération n'est appelée automatiquement.

## Vérification et limites

Les contrôles du code `2691a5a` ont enregistré 1 135 tests Vitest, trois tests Node,
14 drivers d'extension et 16 suites Python sans échec, ainsi qu'un build réussi.
Le lint a zéro erreur et 201 avertissements. Ce sont des vérifications techniques
sur des fixtures, pas une étude d'efficacité pédagogique.

Les preuves reproductibles les plus proches des nouveaux parcours sont :

```sh
# Depuis un checkout installé et construit ; dossiers de sortie nouveaux.
node apps/lesson-mcp/scripts/headless_smoke.mjs
node apps/lesson-mcp/scripts/http-smoke.mjs .studium-session/api-check
node tools/audit-vscode-harness.mjs .studium-session/pane-check
```

Le deuxième contrôle démarre l'API, utilise plusieurs processus du client CLI,
teste la continuité, exporte et vérifie un rapport, puis arrête son serveur.
Il nécessite aussi le `.venv` Python du [parcours enseignant](../../start/installation.fr.md),
car l'export du rapport s'exécute en Python.
Le troisième teste les assets de production du panneau dans Chrome : il faut
l'environnement navigateur du [guide d'audit](../index.fr.md).
Il ne remplace pas un essai dans le véritable Extension Host de VS Code.

Les configurations des harnais sont documentées à partir de leurs sources
officielles. Une séance authentifiée complète dans chacun des clients, un pilote
enseignant/étudiant, une traduction de toutes les anciennes interfaces et un
hébergement de classe authentifié restent à vérifier ou à construire.
