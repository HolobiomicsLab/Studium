# LC-MS Feature Detection

Detection of chromatographic features (peaks) in raw LC-MS data files.

## When to use
When starting metabolomics data analysis from raw mzML files.

## How to apply
Use MZmine3 or XCMS. Set minimum intensity threshold based on instrument noise level.
