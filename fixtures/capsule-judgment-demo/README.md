# capsule-judgment-demo — capsule-backed JUDGMENT slice

Generated by `tools/build_capsule_judgment_demo.py`. This is the de-risking slice for the
Studium north-star: **real scientific operation is the vehicle; calibrated judgment is the
destination.** Instead of grading whether a learner can run a pipeline, the learner audits a
deliberately-flawed AI *reading* of a **real** executed result — and is graded on the judgment.

## What's here

- `scenes.json` — two `spot_the_flaw` scenes generated by `SpotTheFlawAgent`, each **grounded**
  in a genuine capsule execution via a `reference_result` (figure + landmark + graded checks).
  They differ in flaw count: `s-flaw-subtle` plants 1, `s-flaw-blatant` plants 3.
  **Honesty note on the dial.** In *this deterministic build* (no API key), that 1-vs-3 split is
  produced by the stub LLM reading the outline's `n_flaws` — **not** by the rendered prompt. So this
  fixture demonstrates the *grounding + carrier + two-level shape*, **not** that the prompt dial
  itself drives the variation. The prompt dial's authorability (that `trustworthiness.n_flaws`
  actually flows into the prompt text and varies it, rather than being hardcoded) is proven
  *separately* by `test_trustworthiness_dial_is_authorable_not_hardcoded`. Only `--live` exercises
  the dial end-to-end through a real model. (Varying output trustworthiness this way is the
  prerequisite for making calibration measurable later.)
- `decay.png` — the **real** figure produced by `fixtures/capsule-demo/scripts/run.py` running in
  an isolated `uv` venv (`tools/capsule_runner.py`). The learner audits the AI reading against it.

The real landmark (`k_fit≈0.42`, `half_life≈1.65`) is the ground truth the flawed AI reading
mis-states (e.g. "half-life over an hour"). The planted-flaw answer key lives in each scene's
`claims`; the attached run carries **no answer key**, so showing it is evidence, not a leak.

## Regenerate

```bash
python tools/build_capsule_judgment_demo.py          # deterministic stub LLM (no API key)
python tools/build_capsule_judgment_demo.py --live    # real composer LLM (needs a key)
```

The default uses a deterministic stub LLM injected into the **real** `SpotTheFlawAgent`, so the
agent → validation → grounding path is exercised end-to-end without a key. The stub's prose is
templated; a live model writes richer readings — but both ground on the same verified landmark.
**Not yet proven here:** the *quality* of a live-model generation (needs `--live` + a key).
