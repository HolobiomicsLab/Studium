Studium vocabulary

https://w3id.org/studium#, prefix studium, version 0.1

This namespace names the things a Studium lesson is made of. Version 0.1 holds the 13 scene types of a lesson bundle. Each term is the value written in a bundle: the scene type quiz is https://w3id.org/studium#quiz. Further terms are added to this document; a published term is never renamed.

scene types

https://w3id.org/studium#SceneTypeScheme

The types a scene of a Studium lesson bundle can have: what the learner is asked to do in each.

Les types que peut avoir une scène d'une leçon Studium : ce que l'on demande à l'apprenant dans chacun.

Described on the scene types page of the documentation.

intro

https://w3id.org/studium#intro

A scene in which the learner sees the goal and the path of the lesson.

Scène dans laquelle l'apprenant découvre l'objectif et le parcours de la leçon.

concept

https://w3id.org/studium#concept

A scene in which the learner reads and works with one idea.

Scène dans laquelle l'apprenant lit et manipule une idée.

meta checkpoint

https://w3id.org/studium#meta_checkpoint

A scene in which the learner declares how confident they are (0 to 4), once or before and after.

Scène dans laquelle l'apprenant déclare sa confiance (de 0 à 4), une fois ou avant et après.

quiz

https://w3id.org/studium#quiz

A scene in which the learner chooses an answer.

Scène dans laquelle l'apprenant choisit une réponse.

spot the flaw

https://w3id.org/studium#spot_the_flaw

A scene in which the learner finds the errors in a deliberately flawed text.

Scène dans laquelle l'apprenant repère les erreurs d'un texte volontairement fautif.

ai critique

https://w3id.org/studium#ai_critique

A scene in which the learner critiques an AI production.

Scène dans laquelle l'apprenant critique une production de l'IA.

explain back

https://w3id.org/studium#explain_back

A scene in which the learner explains the idea in their own words, as if teaching it.

Scène dans laquelle l'apprenant explique l'idée avec ses mots, comme s'il l'enseignait.

comparison

https://w3id.org/studium#comparison

A scene in which the learner compares two objects or explanations.

Scène dans laquelle l'apprenant compare deux objets ou deux explications.

summary audit

https://w3id.org/studium#summary_audit

A scene in which the learner checks an AI summary for omissions and distortions.

Scène dans laquelle l'apprenant vérifie les omissions et déformations d'un résumé produit par l'IA.

prompt practice

https://w3id.org/studium#prompt_practice

A scene in which the learner writes or improves a prompt for a task.

Scène dans laquelle l'apprenant rédige ou améliore une consigne pour une tâche.

communication sim

https://w3id.org/studium#communication_sim

A scene in which the learner communicates a message to an audience, in a professional role.

Scène dans laquelle l'apprenant transmet un message à un public, dans un rôle professionnel.

discussion

https://w3id.org/studium#discussion

A scene in which the learner reasons with a tutor over several turns.

Scène dans laquelle l'apprenant raisonne avec un tuteur sur plusieurs tours.

reproduction

https://w3id.org/studium#reproduction

A scene in which the learner has the harness run a protocol, then examines the result.

Scène dans laquelle l'apprenant fait exécuter un protocole par le harnais, puis examine le résultat.
