B2 interface and wording notes — source baseline 6f7aa15; no docs or dist generated.
IFACE completion: complete transitions carry completion={consolidated:string[],practised:{concept_id:string,answers:number}[],not_measured:string[]}. Consolidated requires total_attempts >= imported MIN_MASTERY_ATTEMPTS (3) and mastery >= imported REVIEW_MIN_MASTERY (0.6). VS Code completion.ts accepts this shape; its driver passes.
IFACE mastery: presentation.learnerSnapshot.conceptMastery and complete.summary.mastery list every lesson concept with null until at least one graded answer measured it. File completion uses the same split and concept titles, including after a final recall rating.
IFACE graph: get_workflow_graph concept nodes carry attrs.mastery=null when unmeasured and omit the optional numeric value. Measured nodes retain value and attrs.mastery. GraphView schema remains valid.
IFACE verdict: correct_choice references render under “The right answer:” / « La bonne réponse : » with French NBSP. ✓ requires correct===true; ✗ requires correct===false. A keyed verdict from an agent-drafted lesson carries the provenance sentence below, including on the final answer.
IFACE sources: citedSources passes optional bibliographic_refs[].license. Source blocks render title (url), licence when supplied; missing optional URLs/licences are omitted, never invented. Quotations use “ ” in English and « NBSP … NBSP » in French. Reading scenes show formatted Source blocks in chat and task.md; answer-bearing sources remain withheld until earned.
IFACE authoring: served top-level/presentation/operator-context authoring.drafted_by is agent|learner|teacher, inferred by mode for older bundles. Teacher review keeps its prior raw declaration/null semantics; only its TypeScript Omit was adjusted for this added learner field.
IFACE notice: French learner notices use tes/ta/ton/conteste. The English opening notice says “provided reference”, since it appears before an answer. The reproduction-assessment sentence is appended only if this bundle contains a reproduction scene, with or without a judge.
IFACE stale approval: first chat screen and first file task show the one-line stale-approval notice below if approval.recorded && !approval.matches. The saved approval is not changed.
IFACE recall: rate_recall always returns the updated lesson-specific review_plan={next_due_at,next_due_date,concepts}, including before completion. Existing all-concept scheduling, e.moved, persistLearner moved lists and session-clock rated_at are retained and regression-tested.
IFACE recall expiry: MCP isError response includes code="self_rating_expired" and the engine's explicit expiry/re-answer message.
IFACE file channel: after a requested self-rating, ingest returns {done:false,transition:"awaiting_recall"}; task.md requests response.json {kind:"recall",grade:"again"|"hard"|"good"|"easy"}. A valid grade resumes with recall_rated or completes after the final scene. index.json retains pending_recall={scene_id,after,locale}. Invalid structures are consumed; incomplete JSON waits. No model invents a learner grade.
IFACE runner: OperatorCtx.sceneType="recall" for that turn. makeLlmOperator requires an explicit recallRating(task,ctx) callback; without one it errors “Recall rating must come from the learner: supply a recallRating callback.” stubOperator supplies a synthetic good rating for synthetic test runs only.
IFACE file feedback: uses the canonical host verdict, so no-judge answers have a no-judge line, explicit boolean marks and earned references/sources. Final completion retains measured/practised/unmeasured groups after the learner rates recall.

IFACE typography: French catalogues and rendered source blocks use U+00A0 before : and inside guillemets, U+202F before ; ! ?, preserving code spans. English lists/quotes use “ ”. Teacher-facing vous is preserved.
IFACE review: review.items[].bundle_ref identifies the source lesson. Review quiz shuffle salt is [learner_id,"review",calendarDate(now_ms,host.timeZone)]; the session holds its shuffled bundle so letters stay fixed while open. A new review on a new local day receives that day's salt. Lesson order keeps the existing deterministic per-learner/shared-class policy (STUDIUM_PER_LEARNER_SHUFFLE); lesson resume across restarts/days retains its letters.
IFACE submit_response description: “Lesson quiz choices keep a deterministic order for each learner, including on resume. Review choices are shuffled and relettered by learner and review day in the host's time zone; an open review keeps its letters. Send the DISPLAYED choice id, never a memorized source id.”
IFACE teacher tools: registered review_lesson and class_report receive host.libraryRoot and can inspect a lesson authored into the separate learner library. create_lesson rejects a course_id already served from a distinct BUNDLES_ROOT, including overwrite:true; existing conflict wording is retained.
IFACE forget/storage: complete learner writes and forget share the per-learner cross-process lock. Forget waits for pending engine/store writes, rotates a durable generation token, erases learner records and closes that learner's local sessions; an old session in another host is refused even after a fresh profile is created. .learner-locks/<pseudonym>/tombstone remains outside erased learner folders. It holds a random generation only. Existing served persistence warnings are retained on write-through failure.
IFACE storage helpers: withLearnerLock(dataDir,pseudonym,fn), readLearnerTombstone(dataDir,pseudonym), writeLearnerTombstone(dataDir,pseudonym). The write helper requires the lock. Do not clear metadata on ordinary forget or acquire the lock recursively.
