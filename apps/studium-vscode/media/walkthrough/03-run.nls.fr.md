# Exécuter une reproduction

Certaines scènes vous demandent de **reproduire une vraie opération scientifique**. L'opération est le
*véhicule* ; un jugement calibré est la *destination*.

- Sur une scène de reproduction, cliquez sur **Lancer la reproduction** dans le panneau de la leçon (aussi
  dans la barre latérale Studium).
- Studium vous montre d'abord une fenêtre avec la **commande exacte**, les **paquets à installer** et le
  **dossier** d'exécution. Rien ne démarre avant votre confirmation. **« Exécuter et faire confiance à ce
  cours »** retient ce choix pour cette version exacte du cours ; toute modification redemande.
- La capsule s'installe et tourne **dans le dossier de votre espace de travail**, et Studium n'exécute
  jamais rien lui-même. Un dossier d'exécution absolu ou qui sort de l'espace de travail (`..`) est refusé.
- Le **repère** (landmark) que VOUS produisez (par exemple `MODIFIED_COSINE=0.6477`) fonde la scène de
  jugement suivante.

Après l'exécution, Studium indique si votre run est **attesté** (il fonde le jugement) ou **mis en
quarantaine** (incohérent avec le manifeste déclaré ; le jugement utilise alors le run de référence).

> « Attesté » veut dire cohérent avec le manifeste déclaré, **pas** « authentifié » : l'attestation est
> structurelle, pas cryptographique.
